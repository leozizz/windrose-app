# User Story Formulation (Windrose)
- Structure: Como [viajante], eu quero [acao], para que [beneficio].
- Write acceptance criteria in Gherkin: Given (Dado), When (Quando), Then (Entao).
- Explicitly cover edge cases: city not found (404), upstream weather/places timeout (525/429 fallback), empty swipe deck, localStorage persistence, and keyboard swipe alternatives.
